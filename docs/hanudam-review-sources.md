# 하누담 홈페이지 방문자 리뷰 캡처 출처

2026-10-01에 [하누담 네이버 플레이스 방문자 리뷰](https://m.place.naver.com/restaurant/1745436509/review/visitor)에서 실제 방문자 리뷰 5개의 화면을 BrowserOS Neo로 확인하고 캡처했다. 원문 문장, 별점, 방문 정보, 선택한 평가 항목은 원래 표기를 유지했다.

고객 아이디와 프로필이 있는 상단 영역, 업체 답글, 리뷰 사진은 캡처 범위에서 제외했다. PDF로 캡처한 뒤 각 리뷰의 아래쪽 빈 여백을 잘라 WebP로 저장했다. 문장을 다시 쓰거나 합성하지 않았다. 홈페이지 리뷰 섹션에 원본 페이지로 이동하는 출처 링크를 두었다.
